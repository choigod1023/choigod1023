### 🛡️ VIGILIAN — AI 搭載 SOC アシスタント 🏆

> SOC アナリスト向けの AI セキュリティ運用アシスタント。チャット UI でインシデントをリアルタイム分析し、Google Gemini で**対応プレイブックを自動生成**、ReactFlow でプレイブックをインタラクティブに可視化します。AI の応答は SSE でストリーミング。

> **担当:** フルスタック（フロントエンド・バックエンド 100%）および技術アドバイザー · **技術:** React 18, TypeScript, Vite, Tailwind CSS, TanStack Query, Express.js, MongoDB, Google Gemini, Docker
>
